Generated by an `/improve-animations` audit against commit `f7144a0`. See the audit summary delivered in the originating conversation for the full vetted findings table (12 items) and 5 missed-opportunity notes — these three plans are the HIGH-severity subset selected for execution.

If you have the full skill installed elsewhere, a re-run there may use slightly different plan formatting, but the findings themselves were verified directly against this codebase either way.

## Recommended execution order

1. **002 first.** It's a 3-line change confined to `lib/motion/variants.ts` with no component-level edits, so it's the lowest-risk and fastest to land, and it improves several surfaces (popover, dialog, listItem) at once.
2. **003 next.** Single-file, single-component change in `episode-row.tsx`, independent of 001 and 002.
3. **001 last.** Slightly larger in scope (touches two files — `captions-panel.tsx` and `components/ui/page.tsx`'s shared `Skeleton`) and is worth its own focused review pass given it's an accessibility fix, not just a polish fix.

No plan depends on another; all three can also be executed in parallel by separate agents/worktrees if preferred. Each plan is fully self-contained — an executor needs no other context from this session.
